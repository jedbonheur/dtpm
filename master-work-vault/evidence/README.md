# Evidence

Verifier records live here. One file per completed or failed verification attempt.

Naming: `{PACKET_ID}-{YYYYMMDD}-{verdict}.md` using [templates/evidence-record.md](../templates/evidence-record.md).

Example: `P00-WP01-20261028-pass.md`

A ledger row may move to `done` only when a **pass** file exists and the Verifier is not the Implementer.

Until the first verification, this directory contains only this README.
